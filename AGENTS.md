# demo-video (agent fallback)

Agents that do not load skills automatically: when the user asks for a demo video (데모 영상, 시연 영상, screen recording, walkthrough), read `~/.agent-skills/demo-video/skills/demo-video/SKILL.md` first and follow it. It defines the four approval gates and the `dv.py` commands; do not record before G3 is approved.

Teams paste this paragraph into their own project's AGENTS.md.
